# ADR-001: 连续监督器使用原子 DCP 与验证分片恢复

## 状态

Accepted

## 日期

2026-09-17

## 背景

四卡训练环境可能在长任务中终止进程。一次长训练进程无法安全假定其退出会在 checkpoint 完成之后发生。

## 决策

训练保持连续监督，但每 20 step 原子发布一个 DCP completion marker。每个 100-step 验证的四个起点分别发布 shard marker。监督器或主机进程被终止后，cron 只从最新完整 DCP 与缺失 shard 恢复。

## 备选方案

- 只保存最终 checkpoint：丢失工作量过大，且无法审计验证。
- 使用不带完成 marker 的目录：无法区分部分写入与完整状态。
- 主动按时暂停：降低吞吐并且不满足连续训练需求。

## 后果

- 目录结构和 marker 是恢复协议的一部分，不得手工覆盖。
- 已完成验证 shard 不重复生成。
- 出现语义错误时保持 fail-closed，而不是自动无限重试。
